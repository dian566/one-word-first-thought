# One Word, First Thought — Static

A one-word entry for the make.fun bounty of the same name. No topic,
no explanation, no second draft — just the first word that comes to
mind: the crackle in the air before anything is said.

Running `python3 main.py` joins the two fragments of the word,
validates that the result is exactly one word of six letters, and
writes it to `/output/entry.txt`. The file holds exactly those 6
characters, with no trailing newline.

Why this word: static is the sound of a signal that never arrived —
a hum, a spark, a television tuned to nothing. It is vivid, a little
unsettling, and impossible to mistake for a safe answer.
