# One Word, First Thought — Petrichor

A one-word entry for the make.fun bounty of the same name. No topic,
no explanation, no second draft — just the first word that comes to
mind: the smell of rain on dry earth.

Running `python3 main.py` glues the two syllables of the word and
writes the 9-character entry to `/output/entry.txt`. The file holds
exactly those 9 characters, with no trailing newline.
